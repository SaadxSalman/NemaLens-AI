1. **Is Vanna open-source?*
   Yes, Vanna OSS is open-source.  

2. **What is Vanna Cloud?**  
   A hosted version of Vanna with additional managed features.  

3. **Can Vanna run offline?**  
   Yes, using Ollama and ChromaDB with pre-downloaded weights.  

4. **Does Vanna work with SQL databases?**  
   Yes, it supports all SQL databases that Python can connect to.  

5. **How does Vanna execute SQL queries?**  
   Using the `vn.run_sql` function, which returns a pandas DataFrame.  

6. **Can I change the ChromaDB storage path?**  
   Yes, by passing a `'path'` parameter in the config object.  

7. **Why is `vn.ask` too slow or stuck in a notebook?**  
   It may be due to Plotly, an unresponsive LLM, or an exhausted SQL engine.  

8. **How can I speed up `vn.ask`?**  
   Disable visualization (`visualize=False`), check LLM responses, or optimize SQL queries.  

9. **Why is Vanna not responding after training?**  
   The training data might exceed the LLM context window, or there could be corrupted SQL statements.  

10. **How to fix Vanna returning gibberish or errors?**  
   Check if SQL training data is correctly formatted and not corrupted.  

11. **How can I view my training data?**  
   Use `vn.get_training_data()`.  

12. **Can I remove specific training data?**  
   Yes, using `vn.remove_training_data(id='row_id')`.  

13. **Can I retrain Vanna from scratch?**  
   Yes, by clearing old training data and adding new ones.  

14. **How can I train Vanna on additional SQL examples?**  
   Enable `auto_train=True` when running `vn.ask` or `vn.generate_sql`.  

15. **Can I train Vanna using my SQL database schema?**  
   Yes, by ensuring the training data includes `SELECT * FROM INFORMATION_SCHEMA.COLUMNS`.  

16. **What happens if I train Vanna with incorrect SQL?**  
   It may return inaccurate results or fail to generate queries.  

17. **Can Vanna summarize query results?**  
   Yes, using additional LLM functions.  

18. **How do I connect a SQL DB not listed in the documentation?**  
   Implement a custom `run_sql` function for your database.

   No, Vanna is designed specifically for SQL databases.  

20. **How can I optimize SQL queries generated by Vanna?**  
   Train Vanna with well-structured, optimized SQL examples.
